## 조작

- **터치 이동(기본)**: 가고 싶은 곳을 누르면 길을 찾아 걸어갑니다. 나무·바위·밭·사람을 누르면 다가가서 **알아서 상호작용**(걸어다니는 NPC는 따라가서 말을 겁니다). 우리 집을 누르면 들어가고, 가게 건물을 누르면 주인에게 말을 겁니다. 누른 채 끌면 그 방향으로 계속 걷기.
- **조이스틱(설정)**: 화면 왼쪽 아래(또는 오른쪽 — 설정)를 누르면 그 자리에 조이스틱이 생깁니다.
- **액션 버튼**(오른쪽 아래): 바라보는 대상에 맞게 아이콘이 바뀝니다 (밭 갈기 · 심기 · 물 주기 · 수확 · 채굴 · 벌목 · 낚시 · 공격 · 대화 …).
- **핫바 8칸**: 누르면 선택, 한 번 더 누르면 사용(먹기·입기·가구 놓기). 가방·보관함은 바둑판 칸이고, 누르면 설명과 할 수 있는 일이 나옵니다. 가방에서는 칸을 끌어서 옮깁니다.
- 알림은 캐릭터를 가리지 않게 캐릭터 반대쪽(위/아래)에 뜨고, 자동 저장되면 작게 알려 줍니다(30초에 한 번).
- PC 키보드: WASD/방향키 이동, Space·E 액션, I 가방, C 캐릭터, T 순간이동, H 하우스, M/Esc 메뉴, 1~8 핫바.

## 온라인 구조 — 아콰이어 온라인과 같은 서버, 저장 위치는 분리

아콰이어 온라인의 "상시 서버 모드"와 **같은 Firebase 프로젝트(`acquire-950a0`)** 를 씁니다. 서버 프로세스 없이 정적 호스팅(GitHub Pages)에 그대로 얹힙니다.

| | 아콰이어 온라인 | 하하호호 하우스 키우기 |
|---|---|---|
| Firebase 프로젝트 | `acquire-950a0` | 같음 |
| DB 저장 위치 | `/rooms/{방코드}`, `/usage` | **`/hahahoho/worlds/{세계코드}`** |
| 브라우저 저장 키 | `acquire.*` | **`hahahoho.*`** |

세계 하나의 구조:

```
hahahoho/worlds/{코드}/
  meta        세계 이름 · 만든 시각(모든 사람의 공용 시계 기준)
  players/{id} 캐릭터 저장본 (JSON 문자열 — 본인만 씀)
  pub/{id}    위치·방향·모습·말풍선 (움직일 때 초당 약 7번)
  farm/{칸}   밭 한 칸씩
  nodes/{맵}/{자원} 베어진 나무·캐낸 바위가 다시 나는 시각
  house       집 레벨 · 기부금 · 가구 배치
  chest       공용 보관함
  waypoints   깨운 석상
  chat        최근 대화 40개
  helper      밭 일꾼 고용 기한
```

- **공유 세계는 칸마다 트랜잭션**으로 고칩니다. 두 사람이 같은 작물을 동시에 수확해도 한 명만 받습니다.
- **NPC 위치 · 광산/유적 지형 · 시장 시세 · 오늘의 부탁**은 시계와 씨앗으로 계산하므로 동기화하지 않아도 모두 같은 것을 봅니다(트래픽 0).
- 몬스터는 각자 화면에서 따로 돌고 보상도 각자 받습니다.
- 끊겼다 다시 들어오면 저장된 위치에서 이어지고, 다른 사람에게는 "자리 비움"으로 보입니다.
- 이 기기의 **저장 슬롯 3개**에는 어느 세계의 어느 캐릭터인지와 캐릭터 백업본이 들어 있습니다. 서버에서 캐릭터가 사라졌다면 백업으로 되살립니다.

### ⚠️ 한 번만 해 줄 일: DB 보안 규칙 게시

지금 Firebase에 게시된 규칙은 아콰이어용이라 `/hahahoho` 경로 접근이 막혀 있습니다. 게시하지 않으면 온라인 세계를 만들 때 "서버가 접근을 거부했습니다" 안내가 뜹니다.

1. <https://console.firebase.google.com> → `acquire-950a0` → **Realtime Database → 규칙**
2. 기존 내용을 지우고 이 폴더의 **`database.rules.json` 전체**를 붙여넣고 **게시**
   - 이 파일에는 **아콰이어의 규칙(`rooms`, `usage`)이 그대로 들어 있고** `hahahoho` 부분만 추가되었습니다. 아콰이어는 영향을 받지 않습니다.

`fireconfig.js`의 값은 공개용 식별자라 커밋해도 됩니다(아콰이어와 같은 파일). 값을 비우면 서버 없이 **이 기기에만 저장되는 혼자 하기 모드**로 동작합니다.

### 한계

- 정적 호스팅 + DB 구조라 서버에서 규칙을 검사하지 않습니다. 개발자 도구로 자기 캐릭터 값을 고칠 수는 있습니다(협동 게임이라 수용한 절충, 아콰이어와 같은 방식).
- 세계는 자동으로 지우지 않습니다(방치형이라 오래 보관). 무료 한도(Spark: 저장 1GB, 다운로드 월 10GB) 안에서 소규모로 쓰기에 충분합니다.
- `?net=local`(개발용)에서 같은 브라우저의 여러 탭으로 참가할 수는 있지만, 탭 사이 트랜잭션은 원자적이지 않습니다. 실제 멀티플레이는 Firebase에서 하세요.

## 실행 · 테스트 · 배포

```bash
cd hahahoho
python3 -m http.server 8790        # → http://localhost:8790/
# 서버 없이 이 기기 저장으로 테스트: http://localhost:8790/?net=local
npm test                           # 로직·맵·게임 통합 테스트 39개 (Node 18+)
```

- **배포**: 이 폴더가 `main` 브랜치에 들어가면 GitHub Pages가 `https://jinoflow0624.github.io/sns-trend/hahahoho/` 로 바로 서빙합니다. 빌드 과정 없음.
- **모바일**: `manifest.webmanifest` + 서비스 워커가 있어 휴대폰에서 "홈 화면에 추가"하면 앱처럼 전체 화면으로 열립니다. 앱 스토어 출시가 필요하면 이 폴더를 그대로 Capacitor 등의 웹뷰로 감싸면 됩니다.
- 주소 옵션: `?w=코드` 초대 · `?net=local` 서버 없이 · `?debug` 자동 테스트용 훅(`window.__hh`)
