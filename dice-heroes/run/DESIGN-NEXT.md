# 원정 디자인 보강 요청서 (v0.38.11 기준)

v0.38.7 에서 적 16종 · 유물 37종 · 지도 · 카드 틀 · 장면 그림을 정식본으로 바꿨습니다. 그 뒤 시스템 세션에서 기능이 많이 늘었습니다.
그런데 새로 생긴 화면과 요소는 **아직 공용 12×12 아이콘이나 CSS 도형으로 임시 처리**되어 있습니다. 이 문서는 그 목록입니다.

- 원정은 **테스트판 전용**입니다 (`dice-heroes/CLAUDE.md`). `main` 에 합치면 테스트판에 반영되고, 배포판 배포는 하지 않습니다.
- 화풍 · 크기 규칙은 기존 요청서 `run/ASSETS.md` · `run/RELICS-ART.md` 와 같습니다.
  - 도트, 외곽선 `#1A1030`, 빛은 왼쪽 위에서.
  - UI 아이콘은 128px webp, 장면 그림은 512px webp.
- 그림을 넣는 곳은 항목마다 적었습니다. 대부분 `run/art.js` 의 목록에 id 만 더하면 화면이 그 그림을 씁니다.

## 우선순위 A — 지금 화면에서 가장 어색한 것

### 1. 「보존」 키워드 아이콘

- 효과: 턴이 끝나도 버려지지 않고 손패에 남는다. 키워드 색은 `#C8A2FF`.
- 지금은 공용 자물쇠 아이콘을 쓰고 있고, 키워드 9종 중 이것만 정식 그림이 없습니다.
- 콘셉트: 카드 한 장을 감싼 보랏빛 리본이나 쇠고리. "붙잡아 둔다"는 느낌이면 됩니다.
- 넣을 곳: `assets/run/ui/kw_keep.webp` (128px) 를 만들고, `run/art.js` 의 `UI.kw` 에 `'keep'` 을 추가합니다.

### 2. 효과가 여러 개인 카드 (v0.38.10)

- 카드 한 장에 효과가 **최대 3개**까지 붙습니다.
- 지금은 효과 칩을 한 줄로 나란히 놓고, 3개면 아이콘만 보입니다 (`run/run.css` 의 `.rc-kws`). 80px 카드라 많이 빽빽합니다.
- 요청: 효과 2개 · 3개일 때의 카드 하단 레이아웃을 새로 디자인해 주세요.
  - 예: 카드 아래 테두리에 박힌 보석 슬롯 3칸. 효과가 붙으면 그 키워드 색 보석이 끼워지는 식.
- 효과 2개 이상이면 전설 테두리입니다. 효과 3개인 카드는 전설보다 한 단계 더 특별해 보이면 좋겠습니다 (반짝임이나 테두리 장식).
- 카드 앞면은 `run/ui.js` 의 `cardFace()`, 스타일은 `run/run.css` 의 `.rc-in` 입니다.

### 3. 별조각 (원정 밖 성장 화폐)

- 원정이 끝날 때마다 얻고, 「원정 준비」에서 씁니다.
- 지금은 공용 별 아이콘(`ico('star')`)을 씁니다. 처음에는 `✦` 글자를 썼는데 도트 글꼴에 없어서 깨졌습니다.
- 요청: 별조각 아이콘 (작게 12px · 24px 로도 알아볼 것, 금빛 별 조각 · 결정).
- 넣을 곳: `assets/run/ui/star.webp`.

### 4. 「원정 준비」 화면 (원정 밖 성장, v0.38.11)

- 직업 고르기 화면 → 「원정 준비」 버튼 → 창이 열립니다 (`run/ui.js` 의 `showMeta()`).
- 지금은 글자 목록과 공용 아이콘뿐이라 성장하는 손맛이 약합니다.
- 영구 강화 7종의 아이콘 (128px):

| id | 이름 | 효과 | 콘셉트 |
|---|---|---|---|
| `hp` | 강인함 | 시작 최대 체력 +2/단계 (5단계) | 두근거리는 심장 + 단단한 갑옷 조각 |
| `gold` | 여비 | 시작 골드 +20/단계 (3) | 끈 묶은 동전 주머니 |
| `tools` | 도구 주머니 | 시작 뒤집기 +1 · 조정 +1 (2) | 뒤집기 화살표와 미세 조정 다이얼이 든 가죽 주머니 |
| `potion` | 물약 띠 | 회복 물약 1개를 들고 출발 (1) | 물약 병을 꽂은 가죽 띠 |
| `relic` | 보물 지도 | 출발할 때 일반 유물 1개 (1) | X 표시가 있는 낡은 지도 |
| `sharp` | 연마된 덱 | 대표 카드 점수 +30% (1) | 숫돌 위에서 빛나는 카드 |
| `slot` | 주사위 칸 | 특수 주사위 칸 (2) | 빈 주사위 받침대 (보석 홈) |

- 넣을 곳: `assets/run/ui/meta_<id>.webp`. 같은 방식으로 `UI` 목록에 `meta` 종류를 추가하면 됩니다 (`runIco('meta', id, …)` 로 바꾸는 건 시스템 세션이 해도 됩니다).
- 화면 자체 디자인(선택): 지금은 목록형입니다. 야영지 · 작업대 같은 배경 장면 한 장(512px, `assets/run/scene/camp.webp`)과, 단계가 차오르는 칸 표시가 있으면 좋겠습니다.

### 5. 특수 주사위 4종 (v0.38.11, 디자인 비중이 가장 큼)

- 눈은 1~6 그대로인데, 나오는 눈이 다릅니다.
- 지금은 **3D 주사위 모양은 그대로**이고, 주사위 아래에 그 색의 마름모 보석(`.sdie-tag`)만 붙습니다. 「원정 준비」 목록의 주사위 그림도 CSS 사각형입니다.

| id | 이름 | 효과 | 색 | 콘셉트 |
|---|---|---|---|---|
| `gold` | 금 주사위 | 1이 나오면 한 번 더 굴림 | `#FFC83D` | 금박 주사위, 눈은 짙은 갈색 |
| `heavy` | 무거운 주사위 | 6이 약 1/4 | `#9AA4B8` | 납으로 된 묵직한 쇳빛 주사위, 6의 면이 살짝 두꺼움 |
| `twin` | 쌍둥이 주사위 | 1/3 확률로 다른 주사위와 같은 눈 | `#FF9AD0` | 분홍 반투명, 안에 작은 주사위 그림자가 겹쳐 보임 |
| `stair` | 계단 주사위 | 1/3 확률로 이어지는 빈 눈 | `#3EE6B4` | 민트 바탕, 모서리에 계단 무늬 |

요청 두 가지:
- **(가) 2D 그림**: 주사위 하나씩, 정면에서 살짝 위로 본 128px. 「원정 준비」 목록 · 설명 창에 씁니다. 넣을 곳은 `assets/run/ui/die_<id>.webp`.
- **(나) 3D 주사위 재질**: 트레이에서 굴릴 때 일반 주사위와 달라 보이게 합니다.
  - 지금 3D 주사위(`dice3d.js`)는 **한 판의 모든 주사위가 같은 스킨**을 씁니다. 주사위마다 다른 재질을 쓰려면 시스템 쪽 작업이 필요합니다.
  - 디자인 쪽에서는 종류별 면 그림 6장(`assets/run/dice/<id>_1.webp` ~ `_6.webp`, 기존 주사위 스킨 면 그림과 같은 규격)과 재질 메모(금속감 · 투명도 · 빛)만 주세요. 3D 연결은 시스템 세션이 합니다.

### 7. 원정 도전과제 12종

- 「도전과제」 창(`showFeats()`)에서 공용 아이콘을 빌려 쓰고 있습니다.

### 8. 공격 · 방어 나누기 막대 (전투 핵심 조작)

- 카드를 누르면 손패 위에 나오는 판입니다 (`splitHTML()`, CSS `.split`).
  - 왼쪽 빨강이 공격, 오른쪽 파랑이 방어. 손잡이, ◀ ▶, 「딱 막기」, 「내기」 버튼이 있습니다.
- 지금은 CSS 줄무늬 막대라서 게임의 가장 중요한 조작치고 밋밋합니다.
- 요청:
  - 막대 틀 (9-slice 가능한 가로 띠).
  - 손잡이 (검과 방패가 맞물린 모양 등).
  - 공격 · 방어 끝 단추 2종.
  - 「딱 막기」 단추.

### 9. 영웅 피격 · 적 보호막

- **피격**: 지금은 CSS 로 할퀸 자국 3줄과 화면 가장자리 붉은 번쩍임을 그립니다 (`.claw`, `.hurt-vig`).
  - 요청: 할퀸 자국 · 물린 자국 · 타격 별 스프라이트 시트 (가로로 4~6프레임). 적 종류에 따라 바꿔 쓰면 더 좋습니다.
- **적 보호막**: 체력바 옆 파란 칸입니다 (`.shield-badge`, 협동 보스와 같은 모양).
  - 요청: 보호막 칸 그림.
  - 보호막이 깨질 때 연출용 파편 그림 (선택).

### 10. 강화 고르기 · 상점 대장장이

- **강화 고르기** (`showUpgrade()`): 「점수 +30%」 또는 새 효과 3개 중 1개를 고르는 창입니다.
  - 요청: 망치로 카드를 두드리는 대장간 분위기의 머리 그림이나 배경.
- **상점 대장장이**: 상점 목록의 한 줄입니다. 지금은 도끼 아이콘입니다.
  - 요청: 대장장이 아이콘 (128px, `assets/run/ui/smith.webp`).

### 11. 빠진 장면 그림

- `assets/run/scene/treasure.webp` 가 없습니다. 보물 칸의 「보물 상자!」 보상 화면에서 그림 자리가 빕니다. 코드 목록에는 이미 있어서 파일만 넣으면 됩니다.
- 「출발 준비!」 화면(보물 지도로 출발 유물을 받을 때)에 쓸 장면도 필요합니다. 동틀 녘 숲 입구에 선 모험가 같은 그림이면 됩니다.
  - 넣을 곳: `assets/run/scene/start.webp`. 연결은 시스템 세션이 합니다.
