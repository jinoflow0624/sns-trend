# 원정 유물 그림 요청서 (Codex 작업용)

키보리아 「원정」(로그라이크, 테스트판 전용)의 **유물 37종** 그림을 그려 주세요.
지금은 공용 12×12 아이콘을 빌려 쓰고 있어서, 여러 유물이 같은 그림(방패 · 별 등)으로 보입니다.
결과물은 **코드 한 파일**(`dice-heroes/run/relic-art.js`)이며, 그림 파일 없이 문자열 도트로 그립니다.

## 1. 할 일

1. `dice-heroes/run/relic-art.js` 의 `RELIC_ART` 객체에 유물마다 항목을 추가합니다 (37개, 아래 목록 순서대로).
2. 다른 파일은 고치지 않습니다. 화면은 `relicIco()` 가 알아서 새 그림을 씁니다. 그림이 없는 유물은 예전 아이콘을 씁니다.
3. 아래 7번의 확인 명령이 모두 통과해야 합니다.

## 2. 형식

```js
export const RELIC_ART = {
  ace: { pal: { w: '#FFFFFF', r: '#E8435A', g: '#FFC83D', G: '#C8860E' }, rows: [
    '................',
    '....kkkkkkkk....',
    // … 16줄
  ] },
};
```

- `rows`: **정확히 16줄, 줄마다 정확히 16글자**.
- `'.'` = 투명. `'k'` = 외곽선 `#1A1030` (`pal` 에 안 적어도 됩니다).
- 다른 글자는 모두 `pal` 에 색을 적습니다 (`#RRGGBB`). 한 그림에 **외곽선 포함 6색 이하**.
- 적 그림(`run/art.js` 의 `MON`)과 같은 형식입니다. 그쪽을 참고하세요.

## 3. 그림 규칙 (게임 전체 화풍)

- **NES 시절 도트 아이콘**입니다. 사물 하나를 정면 또는 살짝 기울여서 그립니다. 글자 · 숫자는 넣지 않습니다.
  예외: 주사위 눈은 점으로 그립니다.
- **외곽선 1px `k` 로 실루엣을 닫습니다**. 위쪽은 밝게, 아래쪽은 어둡게 칠합니다 (빛은 왼쪽 위에서).
  하이라이트 1~2px 은 흰색 `#FFFFFF`.
- 그림은 가운데에 둡니다. 가장자리 1px 은 비워 둡니다 (실제로 쓰는 영역은 14×14).
- 12px · 24px · 48px 로 줄였다 늘였다 하므로, **12px 에서도 알아볼 큰 실루엣**이 중요합니다. 잔무늬는 쓰지 않습니다.
- 서로 비슷한 유물(예: 뒤집기 두루마리와 재굴림의 반지)은 **모양과 주색을 확실히 다르게** 합니다.

## 6. (선택) 큰 그림 파일

64px 이상 그림 파일을 따로 만든다면 다음처럼 넣습니다. 그러면 도트 문자열보다 그 파일을 먼저 씁니다.
- 위치: `assets/run/relic/<id>.webp` (정사각, 투명 배경)
- `relic-art.js` 의 `FILES` 배열에 id 를 적습니다.

## 7. 확인 (모두 통과해야 합니다)

```sh
cd dice-heroes
node --check run/relic-art.js
node test/run.test.mjs     # '유물 그림' 테스트: 16줄 × 16글자, pal 에 없는 글자 없음, 6색 이하, RELICS 에 있는 id
```

화면 확인은 테스트판에서 합니다. 원정 → 아무 직업 → 보상 · 상점 · 영웅 줄의 유물 칸에 새 그림이 보이면 됩니다.

## 8. 반영 규칙

원정은 **테스트판 전용**입니다 (`dice-heroes/CLAUDE.md`).
`main` 에 합치면 테스트판에 반영되고, 배포판 배포는 하지 않습니다.
`config.js` 의 `version` 을 올려 주세요.
