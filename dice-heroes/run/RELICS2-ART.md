# 원정 그림 요청서 2 — 새 유물 29종 · 인장 4종 · 막 징조 12종 (Codex 작업용)

요트 히어로즈 「원정」(로그라이크, 테스트판 전용)에 새로 들어간 것들의 아이콘을 그려 주세요.
지금은 공용 12×12 아이콘을 빌려 쓰고 있어서 여러 개가 같은 그림으로 보입니다.
결과물은 **코드 한 파일**(`dice-heroes/run/relic-art.js`)이고, 그림 파일 없이 문자열 도트로 그립니다.

## 1. 할 일

1. `dice-heroes/run/relic-art.js` 에 항목을 추가합니다.
   - 새 유물 29종 → `RELIC_ART` 객체 (이미 있는 37종 아래에 이어서)
   - 인장 4종 → `SEAL_ART` 객체 (지금 비어 있음)
   - 막 징조 12종 → `OMEN_ART` 객체 (지금 비어 있음)
2. 다른 파일은 고치지 않습니다. 화면은 `relicIco()` · `dotIco()` 가 알아서 새 그림을 씁니다. 그림이 없는 것은 예전 아이콘을 씁니다.
3. 아래 7번의 확인 명령이 모두 통과해야 합니다.

## 2. 형식 (세 객체 모두 같음)

```js
export const SEAL_ART = {
  sun: { pal: { y: '#FFE27A', g: '#FFC83D', o: '#FF8A1A', w: '#FFFFFF' }, rows: [
    '................',
    '.......kk.......',
    // … 16줄
  ] },
};
```

- `rows`: **정확히 16줄, 줄마다 정확히 16글자**.
- `'.'` = 투명. `'k'` = 외곽선 `#1A1030` (`pal` 에 안 적어도 됩니다).
- 다른 글자는 모두 `pal` 에 색을 적습니다 (`#RRGGBB`). 한 그림에 **외곽선 포함 6색 이하**.
- 이미 있는 `RELIC_ART` 37종과 같은 형식입니다. 그쪽 그림을 꼭 먼저 보고 화풍을 맞춰 주세요.

## 3. 그림 규칙 (게임 전체 화풍)

- **NES 시절 도트 아이콘**입니다. 사물 하나를 정면 또는 살짝 기울여서 그립니다. 글자 · 숫자는 넣지 않습니다 (주사위 눈은 점으로).
- **외곽선 1px `k` 로 실루엣을 닫습니다**. 빛은 왼쪽 위에서: 위는 밝게, 아래는 어둡게. 하이라이트 1~2px 은 흰색.
- 가운데에 두고 가장자리 1px 은 비웁니다 (실제 영역 14×14).
- 12px · 24px · 48px 로 쓰입니다. **12px 에서도 알아볼 큰 실루엣**이 가장 중요합니다. 잔무늬 금지.
- 이미 있는 유물과 **모양 · 주색이 겹치지 않게** 합니다 (특히 저울 · 북 · 주사위 · 무지개 계열).

### 주의: `trinity` (세 조각 성표)

- 젤다의 「트라이포스」를 떠올리게 하는 모양을 원했습니다. 하지만 **「트라이포스」는 닌텐도의 등록 상표**라서 **이름은 쓰지 않습니다** (게임 안 이름은 「세 조각 성표」).
- 삼각형 셋이 큰 삼각형을 이루는 모양 자체는 오래된 기하 문양(시에르핀스키 삼각형)이라 써도 됩니다.
- 다만 젤다와 헷갈리지 않게 아래는 피합니다.
  - 젤다 트라이포스 특유의 **번쩍이는 황금색 + 날개 달린 새 문장(하일리아 문장)**
  - 금색 단색으로 똑같이 따라 그리기
- **은색 · 하늘빛 돌 문양**으로 그리고, 가운데 빈 삼각형에 작은 별 하나를 넣는 식으로 우리 것으로 바꿔 주세요.

## 9. 반영 규칙

- 원정은 **테스트판 전용**입니다. `main` 에 합치면 테스트판에 반영되고, 배포판 배포는 돌리지 않습니다.
- `dice-heroes/config.js` 의 `version` 을 하나 올려 주세요 (설치된 앱이 새 파일을 받습니다).
