# 🎲⚔️ 요트 히어로즈 (옛 이름: 다이스 히어로즈)

- 접속 주소 (GitHub Pages): `https://jinoflow0624.github.io/sns-trend/dice-heroes/`
- 초대 링크: `…/dice-heroes/?room=방코드` — 링크를 누르면 바로 그 방 대기실로 들어갑니다.

**요트 주사위 12라운드**에 **경험치 · 레벨업 · 특성 카드 · 공용 의뢰 게시판 · 라운드 이벤트**를 얹은 성장형 주사위 보드게임.
1~4인, 사람과 봇을 섞어서 할 수 있다. 아콰이어 온라인과 같은 구조(순수 룰 엔진 + 화면 분리 + 정적 호스팅)로 만들었다.

> 핵심 루프: **한 번의 굴림(야바위) → 점수 기록 = 경험치 → 레벨업 카드로 캐릭터 빌드 → 매 턴 바뀌는 의뢰를 노림 → 최종 점수**

## 실행

```bash
cd dice-heroes
python3 -m http.server 8777      # → http://localhost:8777
# ?skip  → 스플래시 건너뛰고 타이틀로
# ?demo  → 봇 둘이 바로 대결 (화면 점검용)
# ?debug → 자동 점검 스크립트용 상태 노출
node test/engine.test.mjs        # 룰 엔진 테스트
node sim/simulate.mjs 400 4      # 밸런스 시뮬레이션 (판수, 인원)
```

첫 실행 흐름: **스플래시 → 타이틀(화면 터치) → 튜토리얼 → 파티 편성**. (스토리 인트로는 v0.23에서 뺐다)
두 번째부터는 타이틀 메뉴로 바로 간다.

- **클래식 야추** (v0.27): 굴림 3번 · 12칸 · 상단 보너스뿐인 순수 야추. 뒤집기 · 조정 · 직업 능력 · 의뢰 · 레벨업 · 이벤트가 없고, 캐릭터는 겉모습만 고른다 (`createGame(…, { mode: 'versus', rule: 'classic' })` → `s.classic`, 선수마다 `plain`). 보석 보상은 대전과 같다.
- **도전과제** (v0.29): 54개 · 5분류(족보 · 성장 · 보스 · 대전 · 꾸준함) · 난이도별 보석(브론즈 50 · 실버 150 · 골드 400 · 전설 1000). 단계 과제(series)는 블록 하나에서 브론즈 → 실버 → 골드로 바뀌고, 마왕 과제(secret)는 봉인이 풀린 뒤에만 보인다. 정의는 `achievements.js`(서버와 같은 파일). 보석을 정산한 판만 진행도에 쌓이고(온라인 방은 서버가 방 기록으로, 오프라인은 한 판 상한으로 검사), 보상은 서버 함수 `claimAch` 로 받는다.
- **탑 쌓기** (v0.28): 대전에서는 점수 카드 위에 영웅마다 탑이 선다. 기록한 점수가 그 크기만큼의 블록이 되어 기록한 순서대로 쌓인다(족보별 색, 상단 보너스 · 요트는 금 블록, 레벨 점수는 맨 아래 보라 받침돌). 엔진은 기록 순서를 `p.order` 에 남긴다.
- **대전 연출** (v0.27): 서로 공격하지 않는다. 기록한 점수가 에너지로 뭉쳐 내 영웅에게 스며들며 강화되는 연출(`powerFx`, 효과음 `sfx.powerUp`). 온라인에서 주사위 · 트레이 스킨은 '내 차례!' 알림이 뜰 때 바뀐다.

### 협동 보스 (난이도: 쉬움 · 보통 · 어려움)
보스마다 쉬움을 깨면 보통이, 보통을 깨면 어려움이 열린다.
**v0.22: 난이도 = 체력.** 보스 스킬은 난이도와 상관없이 같고, 난이도가 오를수록 체력이 오른다 (보통 = 쉬움 ×1.04, 어려움 = 쉬움 ×1.05 이상, 늘 쉬움 < 보통 < 어려움). 어려움은 체력이 절반 아래로 떨어지면 **분노**한다.

| 보스 | 능력 (모든 난이도) | 어려움 분노 (체력 절반 아래) |
|---|---|---|
| 🐉 화염룡 이그니스 | **화염 숨결** 4라운드마다 첫 굴림의 가장 높은 주사위가 1로 탐 / **용린 갑옷** 에이스~식스 피해 25% 감소 | 화염 숨결을 2라운드마다 |
| 👹 오크 대장 그로크 | **전쟁의 북** 3라운드마다 굴림 기회 -1 / **약탈** 누가 0점을 적으면 10 회복 | 약탈 회복 두 배 |
| 💀 리치 왕 모르가스 | **운명 비틀기** 3라운드마다 **두 번째 굴림** 직후 주사위 1개 뒤집힘 / **뼈 방패** 4라운드마다 1인당 12 보호막 | 운명 비틀기가 2개 |
| 👑 마왕 릴리스 | **봉인** 홀수 라운드 첫 굴림 뒤 주사위 1개 봉인 (고정·뒤집기·조정 불가, 다시 굴리면 풀림) / **패기** 짝수 라운드는 이벤트 대신 뒤집기·조정 불가 (굴림은 그대로) | 봉인이 2개 |

마왕은 세 보스의 **어려움을 모두 깨면** 해금 연출과 함께 열린다. 보석 보상 1.2배. 전용 배경음악 `assets/bgm/boss_demon.ogg`.

보스 체력 (1인 / 2인 / 3인 / 4인):

| 보스 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 이그니스 | 275 / 520 / 765 / 1010 | 285 / 540 / 795 / 1050 | 295 / 550 / 805 / 1060 |
| 그로크 | 300 / 530 / 795 / 1055 | 310 / 555 / 825 / 1100 | 315 / 560 / 835 / 1110 |
| 모르가스 | 275 / 520 / 765 / 1000 | 285 / 540 / 795 / 1040 | 295 / 550 / 805 / 1050 |
| 릴리스 | 250 / 485 / 730 / 980 | 260 / 505 / 760 / 1020 | 265 / 510 / 770 / 1025 |

봇 시뮬레이션 승률 (`node sim/coop.mjs 100 <보스>`, 조합당 100판, 1인 / 2인 / 4인). 목표: 쉬움 38% · 보통 26% · 어려움 20% (마왕 30 · 21 · 17%)

| 보스 | 쉬움 | 보통 | 어려움 |
|---|---|---|---|
| 이그니스 | 38 / 38 / 36% | 33 / 22 / 20% | 26 / 15 / 18% |
| 그로크 | 34 / 40 / 38% | 26 / 29 / 25% | 19 / 17 / 15% |

| 릴리스 | 33 / 31 / 31% | 25 / 22 / 17% | 29 / 20 / 6% |

체력 표는 `engine.js`의 `HP_TUNE[보스][난이도][인원]` (봇 시뮬레이션으로 맞춘 배율). 체력을 1% 바꾸면 승률이 약 3%p 움직일 만큼 민감하다.

### 뒤집기 · 조정 보유 한도
모든 직업이 뒤집기·조정을 각각 최대 3개까지만 들고 있을 수 있다. 넘친 충전은 1개당 경험치 10으로 바뀌어 다음 점수 기록 때 들어온다.

## 온라인 방 (2~4인, 링크 초대)

**서버 용량 (Firebase 무료 Spark 요금제 기준)**: 행동마다 방 상태(JSON, 2인 약 7KB · 4인 약 10KB) 전체를 올리고 참가자 모두가 내려받는다.
시뮬레이션으로 잰 한 판 내려받기 합계는 2인 약 2.6MB, 4인 약 14MB(접속 신호 제외). 무료 한도가 동시 연결 100개·월 10GB 내려받기라서
동시에 약 100대(4인 방 25개), 한 달에 4인 약 700판 / 2인 약 3,800판이 상한이다. 이 한도는 같은 프로젝트를 쓰는 아콰이어·하하호호와 나눠 쓴다.

메뉴 → **온라인 방** → 방 만들기 → **초대 링크 복사** → 메신저로 전송. 받은 사람이 링크를 열면 그 방 대기실로 바로 들어온다.
방장이 모드·보스·난이도를 고르고 봇을 채울 수 있다. 구글 플레이 출시 후에는 같은 링크가 앱 링크(App Links)로 앱을 연다.

- **서버 없음**: 방 전체(대기실 + 게임 상태)를 Firebase Realtime DB에 JSON 하나로 두고, 각 기기가 트랜잭션으로 자기 행동을 적용한다. 엔진이 시드 난수로 결정적이라 누가 적용해도 같다.
- **Firebase**: 아콰이어 온라인과 **같은 프로젝트**(`fireconfig.js`)를 쓰고 방 경로를 `rooms/DH-코드`로 구분한다. 지금 DB 규칙(`state`는 40만 자 미만 문자열, `seen/토큰`은 숫자) 안에서 동작하도록 맞췄다. 무료 한도(월 10GB)를 아콰이어와 나눠 쓴다.
- **봇 · 연결 끊김**: 봇 차례는 방장 기기가 진행(방장이 없으면 남은 사람 중 첫 번째). 접속 신호가 20초 넘게 없으면 이름표에 `끊김 N초`가 뜬다.
  - 게임 중 방을 나가도 **1분 안에** 돌아오면 같은 자리로 이어서 한다 (메인 화면 **방으로 돌아가기**, 또는 초대 링크 다시 열기).
  - 1분이 지나면 협동·3~4인 대전은 **봇이 그 자리를 이어받고**, **1대1 대전은 기권패**로 끝난다. 봇으로 바뀐 자리는 다시 들어올 수 없다.
- **동기화**: 방 상태가 연달아 바뀌면 밀린 중간 상태는 건너뛰고 최신 상태만 그린다(밀려 있으면 연출도 빨리 넘김). 접속 신호만 바뀐 경우엔 화면을 다시 그리지 않는다. 내 행동은 서버 응답 전까지 중복 입력을 막는다.
- **내 차례 알림**: 차례가 넘어오면 가운데 배너 + 소리 + 진동, 다른 탭을 보고 있으면 탭 제목이 `▶ 내 차례!`로 바뀐다.
- **시험**: 주소에 `?net=local`을 붙이면 같은 브라우저의 탭끼리 방을 만든다 (인터넷 불필요).
- ⚠ claude.ai 미리보기 페이지에서는 외부 연결이 막혀 온라인 방이 열리지 않는다. 위 GitHub Pages 주소에서 동작한다.
- **DB 규칙**: 하하호호 하우스(`../hahahoho/database.rules.json`)의 합친 규칙에 `rooms`가 그대로 들어 있어 추가로 게시할 것이 없다.
- **배포**: 이 폴더가 `main` 브랜치에 들어가면 GitHub Pages가 바로 서빙한다. 빌드 과정 없음. 파일을 바꿨으면 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받는다.

## 앱 구성

| 요소 | 내용 |
|---|---|
| 스플래시 · 타이틀 | 스튜디오 로고 → 도트 밤하늘·성·떨어지는 주사위가 움직이는 타이틀 |
| 직업 그림 (v0.23) | `assets/heroes/<직업>.webp` — 원본 512px 그림(`tools/hero-src/`)에서 배경만 지워 `tools/make_hero_sprites.py` 로 만든다. 도트 격자로 단순화도 시험했지만 AI 그림은 칸 크기가 고르지 않아 얼굴·작은 소품이 깨져서, 원본을 부드럽게 줄여 쓴다. **예전 16×16 도트로 되돌리기**: `pixel.js` 의 `HERO_ART_DEFAULT` 를 `'v1'` 로 (주소에 `?art=v1` 을 붙이면 잠깐 비교). 예전 그림 데이터는 `pixel.js` `SPRITES` 에 그대로 있고, 바꾸기 직전 상태(v0.22.4)는 브랜치 `backup/dice-heroes-art-v1` |
| 영웅 동작 (v0.23) | 점수 공격 때 주사위판 왼쪽 아래에 영웅이 크게 나와 **기운 받기**(주사위 기운이 스며들며 웅크리고 빛남) → **공격**(뒤로 젖혔다 목표 쪽으로 덤벼들며 직업 기술 발사) → 퇴장. 보스 스킬을 맞으면 **피격**(하얗게 번쩍·뒤로 튕기며 붉게 깜빡). 대전은 상대 초상화가 맞는 동작. 동작별 그림을 따로 그리면 `assets/heroes/<직업>_<charge·attack·hurt>.webp` 로 넣고 `pixel.js` `HERO_POSES` 에 적으면 그 동작 동안 그 그림이 쓰인다 |
| 게임 화면 | 스크롤 없이 한 화면. 점수표는 **족보 완성** 버튼(또는 동료 칸)을 누르면 의뢰 게시판 바로 아래에 뜨고 나머지는 어두워진다. 족보가 완성되면(에이스~식스는 같은 눈 3개 이상, 포카인드~요트는 성립) 가운데에 작은 알림이 뜨고 버튼이 깜박인다. 굴림을 다 쓰면 점수표가 저절로 뜬다. 게임 기록은 맨 아래 한 줄(누르면 최근 8줄) |
| 연출 (`fx.js`) | 점수를 적으면 주사위가 에너지로 뭉쳐 구체가 되고 보스(대전은 내 점수)로 날아가 터진다. 점수가 클수록 색·크기·충격이 커지고 요트는 무지개. 20점 이상은 GREAT!·30점 이상 AMAZING!·요트 YACHT!!! 도장, 명중 순간 히트스톱과 0부터 올라가는 피해 숫자, 체력바는 명중 후 하얀 잔상이 늦게 따라 줄어든다. 결과 화면 점수는 카운트업. 보스 등장은 대각선 띠 위에 이름과 거대한 모습. 보스 스킬: 화염 숨결은 주사위가 멈춘 뒤 불타 1이 되고, 운명 비틀기는 주사위가 떠올라 보랏빛 소용돌이 속에서 뒤집히고, 전쟁의 북은 주사위가 쿵쿵 튀며 충격파, 약탈은 동전이 보스에게, 뼈 방패는 뼛조각이 보스를 감싼다. 분노한 보스는 커지고 자기 색(불꽃·독·비전)으로 활활 탄다. 주소에 `?slowfx`를 붙이면 4배 느리게 |
| 사용성 (v0.9) | 설정: 연출 속도(보통·빠르게·최소 — 최소는 공격 구체·보스 등장 생략), 글자 크게, 색약 보조 표시(희귀도 글자·완성 표시 모양), 그래픽 절약(해상도 1배·그림자 끔). 0점 칸은 한 번 더 눌러야 기록. 주사위를 꾹 누르면 뒤집기·조정 결과와 쓸 수 있는 칸. Android 뒤로가기: 창·점수표 닫기 → 게임 중엔 일시정지 메뉴. WebGL이 없는 기기는 2D 주사위. 3D 트레이는 움직임이 없으면 그리기를 쉬고(빛나는 주사위만 있으면 초당 10번), 다른 앱을 보는 동안은 멈춤. 온라인: 연결이 끊기면 '다시 연결하는 중' 표시, 정해진 문구 반응(나이스!·GG 등). 처음 나오는 용어는 한 번씩 설명. 대시보드 기록 백업 코드 복사·복원 |

결과는 룰 엔진이 먼저 정하고, 3D 주사위는 물리로 굴린 뒤 **멈춘 윗면에 그 눈이 오도록 면 배치를 바꿔 끼운다**.
그래서 움직임은 진짜 물리이고 결과는 온라인에서도 모두에게 같다.

### 배경음악을 파일로 바꾸기
`audio.js`의 `BGM_FILES`에 경로만 넣으면 그 트랙은 파일 재생으로 바뀐다.

```js
export const BGM_FILES = { title: 'assets/bgm/title.ogg', adventure: 'assets/bgm/adventure.ogg' };
```

### 구글 플레이 유료 앱으로 내기
정적 웹앱 그대로 **TWA(Trusted Web Activity)**로 감싸는 방법이 가장 가볍다.
1. GitHub Pages 등 HTTPS 주소에 배포 (manifest · sw.js 포함)
2. `npx @bubblewrap/cli init --manifest https://<주소>/dice-heroes/manifest.webmanifest` → `bubblewrap build`로 `.aab` 생성
3. 사이트 루트에 `/.well-known/assetlinks.json` 등록 (주소창 없이 전체 화면으로 뜨게)
4. Play Console에서 유료 앱으로 등록. 광고·인앱 결제 없이 한 번 사면 전부 즐기는 구성

네이티브 기능(진동 세밀 제어, 파일 저장 등)이 더 필요해지면 Capacitor로 옮길 수 있다.

## 검증 방법

보드게임은 "재밌다"를 숫자로 다 잡을 수 없어서 세 단계로 나눠 검증한다.

### 1. 룰 엔진 테스트 — 룰이 의도대로 도는가
`test/engine.test.mjs` (27개, 소급 적용 포함, 협동 보스 능력·특성 후보·의뢰 보상 포함). 요트 점수 계산, 6주사위 최적 조합, 뒤집기·조정 경계, 경험치와 레벨업,

### 2. 몬테카를로 밸런스 시뮬레이션 — 숫자가 한쪽으로 쏠리지 않는가
`sim/simulate.mjs`. 한 수 앞을 보는 봇끼리 수백 판을 돌려 아래 지표를 뽑는다.
특성 카드는 **무작위로 고르게 해서** 카드별 승률을 편향 없이 잰다.

| 지표 | 목표 | 현재 (4인 400판) |
|---|---|---|
| 직업별 승률 | 25% ± 3%p | 21.5 ~ 30.5% (v0.4.2) |
| 자리 순서 승률 | 25% ± 3%p | 20.6 ~ 27.6% ⚠ |
| 한 판 레벨업 횟수 | 4~6회 (2~3턴에 한 번) | 6.27회 ⚠ (조금 잦음) |
| 1·2위 점수 격차 | 게임당 요트 한 칸(50) 미만 | 33.7 ✅ |
| 특성 보유자 승률 | 기준 +8%p 이내 | 일반·희귀 최고 33.6% ✅, 전설 38~40% (레벨 4부터 나와 레벨 빠른 사람이 가져가는 편향 포함) |

2인 300판: 자리 순서 48.7% / 51.3% ✅, 직업 45.9 ~ 57.7% (직업당 약 110판이라 ±5%p 오차, 전사 재확인 필요)

이 초안까지 시뮬레이션을 세 번 돌리며 고친 것:
- 레벨업이 12턴에 7회로 너무 잦아 필요 경험치 곡선을 `20+10n` → `25+15n`으로 올렸다
- 도적이 승률 36%. 뒤집기·조정 **충전 1회가 약 10점 가치**로 나와서, 시작 충전을 3회에서 뒤집기 1회로 줄였다
- 마법사가 약해 경험치 +20% → +35%로 올렸다
- v0.4 명성 제거 후: 음유시인 16% → 의뢰 턴 점수 +1·조정 +1로 24%, 도박사 33% → 요트 +12만 남겨 25%, 전사 상단 조건 55 → 50
- 여섯 번째 주사위(35%)에 굴림 -1 페널티를 붙였다
- v0.5 수도승(남은 굴림 1회당 조정 +1): 평소처럼 두는 봇 4인 600판 승률 26.8% (기준 25%, 다른 직업 21.6~27.4%) → 과하지 않음.
  조정을 모으려고 일부러 일찍 멈추게 한 봇은 오히려 19% · 7%로 떨어졌다 (굴림 1회가 조정 1회보다 값지다)

### 3. 사람 플레이테스트 — 재미있는가 (숫자로 못 잡는 것)
시뮬레이션이 통과한 뒤에 할 일. 3~4명이 3판씩 하고 아래를 기록한다.
- **결정 시간**: 한 턴이 30초를 넘기면 정보가 과한 것 (미리보기 XP 표시가 도움 되는지)
- **레벨업 순간 반응**: 카드 3장 중 고민되는가, 아니면 정답이 뻔한가
- **다운타임**: 남의 턴에 볼 게 있는가 (의뢰를 뺏기는 긴장감)
- **역전 가능성**: 8라운드 시점 꼴찌가 이긴 판이 있었나
- **한 판 더?**: 끝나고 바로 다시 하자는 말이 나오는가 (가장 중요한 지표)

| 아트 | 지금은 이모지 + CSS. 캐릭터 일러스트를 넣으려면 이미지 생성 도구나 에셋 팩이 필요 |

## 파일 구성

| 파일 | 역할 |
|---|---|
| `config.js` | 게임 이름·버전 (이름을 바꿀 때 여기만) |

| `privacy.html` | 개인정보 처리방침 (스토어 등록용 URL) |
| `app.js` | 화면 흐름(스플래시·타이틀·편성·게임·결과), 입력, 연출 순서 (큰 영웅 동작 `actorIn`·`actorPose`) |
| `fx.js` | 화면 전체 입자 연출 (점수 공격 구체, 보스 스킬, 분노 불꽃, 화면 흔들림) |
| `icons.js` | 도트 아이콘 격자와 특성·의뢰·이벤트·보스 능력별 아이콘 표 |
| `skins.js` | 꾸미기: 주사위 스킨 9종(기본·오픈하츠·황금·미니멀·우주·블랙·투명·하트·키캡, 스킨별 굴림 소리) · 트레이 스킨 7종 (캔버스로 그림, 유료 해금 자리 `isUnlocked`) |

| `pixel.js` · `scenes.js` | 스프라이트(그림 파일 · 예전 도트)와 타이틀 장면 |
| `tutorial.js` | 튜토리얼 대본(단계·강조 대상·허용 동작·완료 조건) |
| `style.css` | 도트 프레임 · 픽셀 서체 스타일 |
