# 🎲⚔️ 다이스 히어로즈 (초안 v0.1)

**요트 주사위 12라운드**에 **경험치 · 레벨업 · 특성 카드 · 공용 의뢰 게시판 · 라운드 이벤트**를 얹은 성장형 주사위 보드게임.
1~4인, 사람과 봇을 섞어서 할 수 있다. 아콰이어 온라인과 같은 구조(순수 룰 엔진 + 화면 분리 + 정적 호스팅)로 만들었다.

> 핵심 루프: **한 번의 굴림(야바위) → 점수 기록 = 경험치 → 레벨업 카드로 캐릭터 빌드 → 매 턴 바뀌는 의뢰를 노림 → 최종 점수**

## 실행

```bash
cd dice-heroes
python3 -m http.server 8777      # → http://localhost:8777
# http://localhost:8777/?demo    → 봇 둘이 바로 대결 (화면 점검용)
node test/engine.test.mjs        # 룰 엔진 테스트
node sim/simulate.mjs 400 4      # 밸런스 시뮬레이션 (판수, 인원)
```

외부 라이브러리 없음. 폰트만 Google Fonts에서 받고, 막히면 시스템 폰트로 대체된다.

## 룰

### 기본 — 요트 원룰 그대로
- 12라운드, 매 턴 주사위 5개를 **최대 3번** 굴린다. 누른 주사위는 잡아 두고 나머지만 다시 굴린다.
- 점수표 12칸 중 하나에 **반드시** 적는다 (못 맞추면 0점).

| 칸 | 점수 |
|---|---|
| 에이스~식스 | 해당 눈의 합. 6칸 합이 **63 이상이면 +35** |
| 초이스 | 5개 합 |
| 포카인드 | 같은 눈 4개 이상 → 5개 합 |
| 풀하우스 | 3개+2개 → 5개 합 |
| 스몰 / 라지 스트레이트 | 연속 4개 → 15 / 연속 5개 → 30 |
| 요트 | 5개 모두 같음 → 50 |

### 추가 1 — 경험치와 레벨업
- **적은 점수만큼 경험치**. 0점을 적으면 위로 경험치 8.
- 필요 경험치: Lv1→2 **25**, 이후 레벨마다 +15 (25, 40, 55, 70 …). 최대 Lv10.
- 레벨이 오르면 **특성 카드 3장 중 1장**을 고른다. 등급 확률은 일반 60 / 희귀 30 / 전설 10이고, 전설은 Lv4부터 나온다.

### 추가 2 — 직업 (시작 시 선택)
| 직업 | 능력 |
|---|---|
| 🗡️ 전사 | 상단 보너스 조건 63 → 55 |
| 🗝️ 도적 | 뒤집기 1회를 들고 시작 |
| 🔮 마법사 | 경험치 +35% |
| 🎻 음유시인 | 의뢰 명성 +3 |
| 🎲 도박사 | 요트 +15, 포카인드 +5 |

### 추가 3 — 특성 카드 (17종)
- **기술 충전**: 🔄 뒤집기(주사위를 반대 면으로, 7-눈) · 🎯 미세 조정(±1)
- **항목 강화**: 기초 수련(상단 +2) · 선택의 달인(초이스 +8) · 풀하우스 장인(+10) · 질주(스트레이트 +8) · 사냥 본능(포카인드 +10)
- **성장/명성**: 빠른 성장(경험치 +25%) · 명성 사냥꾼(의뢰 명성 +2) · 보험(0점이면 경험치 +20·명성 +3) · 연쇄 의뢰(한 턴 2개) · 현자의 눈(이후 카드 4장 중 선택)
- **판도 변화**: 재굴림 +1 · 행운의 부적(나온 1은 한 번 더 굴림)
- **전설**: 🌟 여섯 번째 주사위(6개 중 좋은 5개, 대신 굴림 -1) · 👑 황금손(내 턴마다 명성 +2) · ⛵ 요트 신봉자(요트 +40)

### 추가 4 — 의뢰 게시판 (공용, 늘 바뀌는 목표)
- 게시판에 의뢰 3장이 깔려 있다. 점수를 적을 때 **그 주사위가 의뢰 조건을 맞추면** 명성과 경험치를 받는다. 어느 칸에 적든 상관없다.
- 먼저 깬 사람이 가져가고 새 의뢰가 채워진다. 24종: 두 쌍, 합 25↑, 모두 짝수, 연속 5개, 합이 정확히 17, 요트 등.
- 한 턴에 1개(보상이 가장 큰 것). 연쇄 의뢰 특성이 있으면 2개.

### 추가 5 — 라운드 이벤트
매 라운드 1장이 모두에게 적용된다. 1라운드는 항상 평온한 하루.
수확 축제(경험치 2배) · 짙은 안개(굴림 -1) · 순풍(굴림 +1) · 현상금(의뢰 명성 +3) · 명상의 날(0점도 경험치 +20) ·
요트 잭팟(요트 +50) · 풍년(상단 +5) · 결투 대회(라운드 최고 득점자 명성 +5) · 게시판 갱신 · 여신의 축복(모두 뒤집기 +1)

### 최종 점수
**점수표 합계(+상단 보너스) + 명성 + (레벨-1)×3**

## 검증 방법

보드게임은 "재밌다"를 숫자로 다 잡을 수 없어서 세 단계로 나눠 검증한다.

### 1. 룰 엔진 테스트 — 룰이 의도대로 도는가
`test/engine.test.mjs` (15개). 요트 점수 계산, 6주사위 최적 조합, 뒤집기·조정 경계, 경험치와 레벨업,
의뢰 획득과 보드 보충, 봇 4명 20판 완주, **같은 시드 = 같은 게임**, JSON 왕복 후 이어하기(온라인 동기화 전제).

### 2. 몬테카를로 밸런스 시뮬레이션 — 숫자가 한쪽으로 쏠리지 않는가
`sim/simulate.mjs`. 한 수 앞을 보는 봇끼리 수백 판을 돌려 아래 지표를 뽑는다.
특성 카드는 **무작위로 고르게 해서** 카드별 승률을 편향 없이 잰다.

| 지표 | 목표 | 현재 (4인 400판) |
|---|---|---|
| 직업별 승률 | 25% ± 3%p | 23.2 ~ 27.2% ✅ |
| 자리 순서 승률 | 25% ± 3%p | 21.3 ~ 28.5% ⚠ (선 플레이어 약간 유리) |
| 한 판 레벨업 횟수 | 4~6회 (2~3턴에 한 번) | 5.35회 ✅ |
| 점수 중 성장 요소(명성+레벨) 비중 | 15~30% | 21.9% ✅ |
| 1·2위 점수 격차 | 게임당 요트 한 칸(50) 미만 | 43.7 ✅ |
| 특성 보유자 승률 | 기준 +8%p 이내 | 황금손 36.8% ⚠ 조정 후보 |

2인 300판: 자리 순서 48.7% / 51.3% ✅, 직업 45.9 ~ 57.7% (직업당 약 110판이라 ±5%p 오차, 전사 재확인 필요)

이 초안까지 시뮬레이션을 세 번 돌리며 고친 것:
- 레벨업이 12턴에 7회로 너무 잦아 필요 경험치 곡선을 `20+10n` → `25+15n`으로 올렸다
- 도적이 승률 36%. 뒤집기·조정 **충전 1회가 약 10점 가치**로 나와서, 시작 충전을 3회에서 뒤집기 1회로 줄였다
- 마법사·음유시인이 약해 경험치 +20% → +35%, 명성 +2 → +3으로 올렸다
- 여섯 번째 주사위(35%)에 굴림 -1 페널티를 붙였다

### 3. 사람 플레이테스트 — 재미있는가 (숫자로 못 잡는 것)
시뮬레이션이 통과한 뒤에 할 일. 3~4명이 3판씩 하고 아래를 기록한다.
- **결정 시간**: 한 턴이 30초를 넘기면 정보가 과한 것 (미리보기 XP 표시가 도움 되는지)
- **레벨업 순간 반응**: 카드 3장 중 고민되는가, 아니면 정답이 뻔한가
- **다운타임**: 남의 턴에 볼 게 있는가 (의뢰를 뺏기는 긴장감)
- **역전 가능성**: 8라운드 시점 꼴찌가 이긴 판이 있었나
- **한 판 더?**: 끝나고 바로 다시 하자는 말이 나오는가 (가장 중요한 지표)

## 필요한 스킬 / 도구

지금 초안은 **추가 설치 없이** 만들었다 (Node + 브라우저만). 다음 단계에서 쓸 만한 것:

| 필요 | 방법 |
|---|---|
| 확률 계산 (의뢰 난이도 → 보상 책정) | `sim/`에 의뢰별 달성 확률 표를 뽑는 스크립트 추가 (지금은 완료 횟수로 간접 측정) |
| 화면 점검 | Playwright(이 환경에 설치돼 있음)로 `?demo` 모드 자동 스크린샷 |
| 온라인 대전 | 아콰이어의 `room.js` · `net.js` · `fire.js` 이식. 엔진 상태가 JSON + 시드 난수라 거의 그대로 붙는다 |
| 반복 밸런싱 | Claude Code 스킬로 "시뮬 돌리고 ⚠ 지표 고치기" 절차를 묶어 두면 수치 조정을 반복할 때 편하다 (`skill-creator`) |
| 아트 | 지금은 이모지 + CSS. 캐릭터 일러스트를 넣으려면 이미지 생성 도구나 에셋 팩이 필요 |
