# 🎲⚔️ 다이스 히어로즈 (v0.4 · 가제)

- 접속 주소 (GitHub Pages): `https://jinoflow0624.github.io/sns-trend/dice-heroes/`
- 초대 링크: `…/dice-heroes/?room=방코드` — 링크를 누르면 바로 그 방 대기실로 들어갑니다.

**요트 주사위 12라운드**에 **경험치 · 레벨업 · 특성 카드 · 공용 의뢰 게시판 · 라운드 이벤트**를 얹은 성장형 주사위 보드게임.
1~4인, 사람과 봇을 섞어서 할 수 있다. 아콰이어 온라인과 같은 구조(순수 룰 엔진 + 화면 분리 + 정적 호스팅)로 만들었다.

> 핵심 루프: **한 번의 굴림(야바위) → 점수 기록 = 경험치 → 레벨업 카드로 캐릭터 빌드 → 매 턴 바뀌는 의뢰를 노림 → 최종 점수**

## 실행

```bash
cd dice-heroes
python3 -m http.server 8777      # → http://localhost:8777
# ?skip  → 스플래시 건너뛰고 타이틀로
# ?demo  → 봇 둘이 바로 대결 (화면 점검용)
# ?debug → 자동 점검 스크립트용 상태 노출
node test/engine.test.mjs        # 룰 엔진 테스트
node sim/simulate.mjs 400 4      # 밸런스 시뮬레이션 (판수, 인원)
```

첫 실행 흐름: **스플래시 → 타이틀(화면 터치) → 스토리 인트로 → 튜토리얼 → 파티 편성**.
두 번째부터는 타이틀 메뉴(이어하기 · 새 모험 · 튜토리얼 · 스토리 · 설정 · 크레딧)로 바로 간다.

### 협동 보스 (난이도: 쉬움 · 보통 · 매우 어려움)
| 보스 | 능력 | 매우 어려움 분노 (체력 절반 아래) |
|---|---|---|
| 🐉 화염룡 이그니스 | **화염 숨결** 4·3·2라운드마다 첫 굴림의 가장 높은 주사위가 1로 탐 / **용린 갑옷** 에이스~식스 피해 25·50·50% 감소 | 화염 숨결을 매 라운드 |
| 👹 오크 대장 그로크 | **전쟁의 북** 3·2·2라운드마다 굴림 기회 -1 / **약탈** 누가 0점을 적으면 10·20·30 회복 | 약탈 회복 두 배 |
| 💀 리치 왕 모르가스 | **운명 비틀기** 3·2·매 라운드 첫 굴림 직후 주사위 1개 뒤집힘 / **뼈 방패** 4·3·3라운드마다 1인당 12·20·28 보호막 | 운명 비틀기가 2개 |

보스 체력 = 난이도 기본값(170 · 205 · 235) × 보스·난이도별 보정 × 인원 수 × 인원 보정.
인원 보정은 난이도마다 다르다(쉬움은 인원이 많을수록 조금 늘리고, 보통·매우 어려움은 줄인다). 모두 봇 시뮬레이션으로 맞춘 값이다.
봇 시뮬레이션 승률 (`node sim/coop.mjs 80`, 조합당 80판, v0.4 명성 제거 후):

| 보스 · 난이도 | 1인 | 2인 | 4인 |
|---|---|---|---|
| 이그니스 쉬움 / 보통 / 매우 어려움 | 70 / 30 / 20% | 76 / 46 / 24% | 85 / 57 / 31% |
| 그로크 쉬움 / 보통 / 매우 어려움 | 70 / 44 / 30% | 83 / 51 / 36% | 75 / 49 / 30% |
| 모르가스 쉬움 / 보통 / 매우 어려움 | 76 / 46 / 18% | 83 / 45 / 21% | 83 / 44 / 28% |

목표는 쉬움 약 70~80%, 보통 약 40~50%, 매우 어려움 약 15~30% (v0.3의 쉬움 87~100%, 보통 53~77%에서 낮춤).

## 온라인 방 (2~4인, 링크 초대)

메뉴 → **온라인 방** → 방 만들기 → **초대 링크 복사** → 메신저로 전송. 받은 사람이 링크를 열면 그 방 대기실로 바로 들어온다.
방장이 모드·보스·난이도를 고르고 봇을 채울 수 있다. 구글 플레이 출시 후에는 같은 링크가 앱 링크(App Links)로 앱을 연다.

- **서버 없음**: 방 전체(대기실 + 게임 상태)를 Firebase Realtime DB에 JSON 하나로 두고, 각 기기가 트랜잭션으로 자기 행동을 적용한다. 엔진이 시드 난수로 결정적이라 누가 적용해도 같다.
- **Firebase**: 아콰이어 온라인과 **같은 프로젝트**(`fireconfig.js`)를 쓰고 방 경로를 `rooms/DH-코드`로 구분한다. 지금 DB 규칙(`state`는 40만 자 미만 문자열, `seen/토큰`은 숫자) 안에서 동작하도록 맞췄다. 무료 한도(월 10GB)를 아콰이어와 나눠 쓴다.
- **봇 · 자리 비움**: 봇 차례는 방장 기기가 진행. 45초 넘게 접속이 없는 사람 차례에는 다른 사람이 **대신 진행**을 누를 수 있다.
- **시험**: 주소에 `?net=local`을 붙이면 같은 브라우저의 탭끼리 방을 만든다 (인터넷 불필요).
- ⚠ claude.ai 미리보기 페이지에서는 외부 연결이 막혀 온라인 방이 열리지 않는다. 위 GitHub Pages 주소에서 동작한다.
- **DB 규칙**: 하하호호 하우스(`../hahahoho/database.rules.json`)의 합친 규칙에 `rooms`가 그대로 들어 있어 추가로 게시할 것이 없다.
- **배포**: 이 폴더가 `main` 브랜치에 들어가면 GitHub Pages가 바로 서빙한다. 빌드 과정 없음. 파일을 바꿨으면 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받는다.

## 앱 구성

| 요소 | 내용 |
|---|---|
| 스플래시 · 타이틀 | 스튜디오 로고 → 도트 밤하늘·성·떨어지는 주사위·영웅 행렬이 움직이는 타이틀 |
| 스토리 인트로 | 4장면, 한 글자씩 찍히는 대사 상자. 탭하면 넘어가고 건너뛰기 가능 |
| 튜토리얼 | 길잡이 요정 루루가 13단계로 안내. 결과가 정해진 주사위로 굴리기·잡기·의뢰·레벨업·뒤집기·조정을 직접 해 본다. 강조한 영역 밖은 막는 판으로 덮어 눌리지 않고, 버튼이 화면 밖이면 스크롤 방향을 알려 준다 |
| 도움말 | 점수표 칸마다 한 줄 규칙, **족보 보기**(예시 주사위), **의뢰 보상이란?**, 특성·보스 능력·이벤트를 누르면 작은 설명 팝업 |
| 3D 주사위 | three.js + cannon-es 물리. 트레이에 던져져 벽·서로에 부딪히며 구르고, 멈추면 줄을 맞춰 정렬. 부딪힐 때마다 충격에 맞는 딸깍 소리 |
| 사운드 | 패미컴식 4채널 칩튠(펄스 2·삼각파·노이즈)을 WebAudio로 합성. 타이틀·모험·결과 3곡과 효과음 20여 종, 모두 이 게임용으로 새로 작곡 |
| 도트 그래픽 | 직업 5종 + 요정 16×16 스프라이트, 갈무리 픽셀 서체, 9분할 도트 프레임 |
| 앱 형식 | 설정(배경음악·효과음 볼륨·진동), 일시정지, 이어하기 자동 저장, 크레딧, PWA 매니페스트 + 오프라인 캐시(`sw.js`), 아이콘 |

결과는 룰 엔진이 먼저 정하고, 3D 주사위는 물리로 굴린 뒤 **멈춘 윗면에 그 눈이 오도록 면 배치를 바꿔 끼운다**.
그래서 움직임은 진짜 물리이고 결과는 온라인에서도 모두에게 같다.

### 배경음악을 파일로 바꾸기
`audio.js`의 `BGM_FILES`에 경로만 넣으면 그 트랙은 파일 재생으로 바뀐다.

```js
export const BGM_FILES = { title: 'assets/bgm/title.ogg', adventure: 'assets/bgm/adventure.ogg' };
```

### 구글 플레이 유료 앱으로 내기
정적 웹앱 그대로 **TWA(Trusted Web Activity)**로 감싸는 방법이 가장 가볍다.
1. GitHub Pages 등 HTTPS 주소에 배포 (manifest · sw.js 포함)
2. `npx @bubblewrap/cli init --manifest https://<주소>/dice-heroes/manifest.webmanifest` → `bubblewrap build`로 `.aab` 생성
3. 사이트 루트에 `/.well-known/assetlinks.json` 등록 (주소창 없이 전체 화면으로 뜨게)
4. Play Console에서 유료 앱으로 등록. 광고·인앱 결제 없이 한 번 사면 전부 즐기는 구성

네이티브 기능(진동 세밀 제어, 파일 저장 등)이 더 필요해지면 Capacitor로 옮길 수 있다.

## 룰

### 기본 — 요트 원룰 그대로
- 12라운드, 매 턴 주사위 5개를 **최대 3번** 굴린다. 누른 주사위는 잡아 두고 나머지만 다시 굴린다.
- 점수표 12칸 중 하나에 **반드시** 적는다 (못 맞추면 0점).

| 칸 | 점수 |
|---|---|
| 에이스~식스 | 해당 눈의 합. 6칸 합이 **63 이상이면 +35** |
| 초이스 | 5개 합 |
| 포카인드 | 같은 눈 4개 이상 → 5개 합 |
| 풀하우스 | 3개+2개 → 5개 합 |
| 스몰 / 라지 스트레이트 | 연속 4개 → 15 / 연속 5개 → 30 |
| 요트 | 5개 모두 같음 → 50 |

### 추가 1 — 경험치와 레벨업
- **적은 점수만큼 경험치**. 0점을 적으면 위로 경험치 8.
- 필요 경험치: Lv1→2 **25**, 이후 레벨마다 +15 (25, 40, 55, 70 …). 최대 Lv10.
- 레벨이 오르면 **특성 카드 3장 중 1장**을 고른다. 등급 확률은 일반 60 / 희귀 30 / 전설 10이고, 전설은 Lv4부터 나온다.

### 추가 2 — 직업 (시작 시 선택)
| 직업 | 능력 |
|---|---|
| 🗡️ 전사 | 상단 보너스 조건 63 → 50 |
| 🗝️ 도적 | 뒤집기 1회를 들고 시작 |
| 🔮 마법사 | 경험치 +35% |
| 🎻 음유시인 | 의뢰를 깬 턴의 기록 점수 +1, 의뢰 보상 조정 +1 |
| 🎲 도박사 | 요트 +12 |

### 추가 3 — 특성 카드 (17종 + 즉시 보상 3종)
- **기술 충전**: 🔄 뒤집기(주사위를 반대 면으로, 7-눈) · 🎯 미세 조정(±1)
- **항목 강화**: 기초 수련(상단 +2) · 선택의 달인(초이스 +8) · 풀하우스 장인(+10) · 질주(스트레이트 +8) · 사냥 본능(포카인드 +10)
- **성장/의뢰**: 빠른 성장(경험치 +25%) · 의뢰 전문가(의뢰 보상 뒤집기 +1) · 보험(0점이면 경험치 +20·뒤집기 +1) · 연쇄 의뢰(한 턴 2개) · 현자의 눈(이후 카드 4장 중 선택)
- **판도 변화**: 재굴림 +1 · 행운의 부적(나온 1은 한 번 더 굴림)
- 이미 채운 점수 칸에만 붙는 특성은 후보에서 빠지고, 고를 카드가 모자라면 즉시 보상 카드(공구함: 뒤집기+조정 · 조정 꾸러미 · 장인의 공구함)로 채운다
- **전설**: 🌟 여섯 번째 주사위(6개 중 좋은 5개, 대신 굴림 -1) · 👑 황금손(내 턴마다 조정 +1) · ⛵ 요트 신봉자(요트 +40)

### 추가 4 — 의뢰 게시판 (공용, 늘 바뀌는 목표)
- 게시판에 의뢰 3장이 깔려 있다. 점수를 적을 때 **그 주사위가 의뢰 조건을 맞추면** 🔄 뒤집기 · 🎯 조정 충전과 경험치를 받는다. 어느 칸에 적든 상관없다.
- 보상은 난이도별: 쉬움 🎯1 · 보통 🔄1 · 어려움 🔄1+🎯1 · 전설(요트) 🔄2+🎯2. 모은 충전으로 다음 턴에 큰 족보를 노린다.
- 먼저 깬 사람이 가져가고 새 의뢰가 채워진다. 24종: 두 쌍, 합 25↑, 모두 짝수, 연속 5개, 합이 정확히 17, 요트 등.
- 한 턴에 1개(보상이 가장 큰 것). 연쇄 의뢰 특성이 있으면 2개.

### 추가 5 — 라운드 이벤트
매 라운드 1장이 모두에게 적용된다. 1라운드는 항상 평온한 하루.
수확 축제(경험치 2배) · 짙은 안개(굴림 -1) · 순풍(굴림 +1) · 현상금(의뢰 보상 두 배) · 명상의 날(0점도 경험치 +20) ·
요트 잭팟(요트 +50) · 풍년(상단 +5) · 결투 대회(라운드 최고 득점자 뒤집기+1·조정+1) · 게시판 갱신 · 여신의 축복(모두 뒤집기 +1)

### 최종 점수
**점수표 합계(+상단 보너스) + (레벨-1)×3**

> v0.4에서 명성을 없앴다. 점수로만 환산돼 차별점이 약해서, 의뢰·이벤트·특성 보상을 모두 뒤집기·조정 충전으로 바꿨다.

## 검증 방법

보드게임은 "재밌다"를 숫자로 다 잡을 수 없어서 세 단계로 나눠 검증한다.

### 1. 룰 엔진 테스트 — 룰이 의도대로 도는가
`test/engine.test.mjs` (24개, 협동 보스 능력·특성 후보·의뢰 보상 포함). 요트 점수 계산, 6주사위 최적 조합, 뒤집기·조정 경계, 경험치와 레벨업,
의뢰 획득과 보드 보충, 봇 4명 20판 완주, **같은 시드 = 같은 게임**, JSON 왕복 후 이어하기(온라인 동기화 전제).

### 2. 몬테카를로 밸런스 시뮬레이션 — 숫자가 한쪽으로 쏠리지 않는가
`sim/simulate.mjs`. 한 수 앞을 보는 봇끼리 수백 판을 돌려 아래 지표를 뽑는다.
특성 카드는 **무작위로 고르게 해서** 카드별 승률을 편향 없이 잰다.

| 지표 | 목표 | 현재 (4인 400판) |
|---|---|---|
| 직업별 승률 | 25% ± 3%p | 21.7 ~ 28.1% ✅ (v0.4) |
| 자리 순서 승률 | 25% ± 3%p | 20.6 ~ 27.6% ⚠ |
| 한 판 레벨업 횟수 | 4~6회 (2~3턴에 한 번) | 6.27회 ⚠ (조금 잦음) |
| 1·2위 점수 격차 | 게임당 요트 한 칸(50) 미만 | 33.7 ✅ |
| 특성 보유자 승률 | 기준 +8%p 이내 | 최고 32.8% (선택의 달인) ✅ |

2인 300판: 자리 순서 48.7% / 51.3% ✅, 직업 45.9 ~ 57.7% (직업당 약 110판이라 ±5%p 오차, 전사 재확인 필요)

이 초안까지 시뮬레이션을 세 번 돌리며 고친 것:
- 레벨업이 12턴에 7회로 너무 잦아 필요 경험치 곡선을 `20+10n` → `25+15n`으로 올렸다
- 도적이 승률 36%. 뒤집기·조정 **충전 1회가 약 10점 가치**로 나와서, 시작 충전을 3회에서 뒤집기 1회로 줄였다
- 마법사가 약해 경험치 +20% → +35%로 올렸다
- v0.4 명성 제거 후: 음유시인 16% → 의뢰 턴 점수 +1·조정 +1로 24%, 도박사 33% → 요트 +12만 남겨 25%, 전사 상단 조건 55 → 50
- 여섯 번째 주사위(35%)에 굴림 -1 페널티를 붙였다

### 3. 사람 플레이테스트 — 재미있는가 (숫자로 못 잡는 것)
시뮬레이션이 통과한 뒤에 할 일. 3~4명이 3판씩 하고 아래를 기록한다.
- **결정 시간**: 한 턴이 30초를 넘기면 정보가 과한 것 (미리보기 XP 표시가 도움 되는지)
- **레벨업 순간 반응**: 카드 3장 중 고민되는가, 아니면 정답이 뻔한가
- **다운타임**: 남의 턴에 볼 게 있는가 (의뢰를 뺏기는 긴장감)
- **역전 가능성**: 8라운드 시점 꼴찌가 이긴 판이 있었나
- **한 판 더?**: 끝나고 바로 다시 하자는 말이 나오는가 (가장 중요한 지표)

## 필요한 스킬 / 도구

지금 초안은 **추가 설치 없이** 만들었다 (Node + 브라우저만). 다음 단계에서 쓸 만한 것:

| 필요 | 방법 |
|---|---|
| 확률 계산 (의뢰 난이도 → 보상 책정) | `sim/`에 의뢰별 달성 확률 표를 뽑는 스크립트 추가 (지금은 완료 횟수로 간접 측정) |
| 화면 점검 | Playwright(이 환경에 설치돼 있음)로 `?demo` 모드 자동 스크린샷 |
| 온라인 대전 | 아콰이어의 `room.js` · `net.js` · `fire.js` 이식. 엔진 상태가 JSON + 시드 난수라 거의 그대로 붙는다 |
| 반복 밸런싱 | Claude Code 스킬로 "시뮬 돌리고 ⚠ 지표 고치기" 절차를 묶어 두면 수치 조정을 반복할 때 편하다 (`skill-creator`) |
| 아트 | 지금은 이모지 + CSS. 캐릭터 일러스트를 넣으려면 이미지 생성 도구나 에셋 팩이 필요 |

| `tutorial.js` | 튜토리얼 대본(단계·강조 대상·허용 동작·완료 조건) |

| `manifest.webmanifest` · `sw.js` · `icons/` | 설치형 앱(PWA/TWA) |
