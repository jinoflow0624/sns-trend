# 디자인 세션 인계 — 손맛 개편 (2026-10-15)

키보리아 손맛 개편 중 **그림 · 디자인이 필요한 일**만 모았습니다. 코드는 이미 자리를 만들어 두었으니, 그림 파일을 넣고 목록에 id 를 적으면 바로 화면에 나옵니다.
게임 화풍: **NES 시절 16비트 감성 도트**, 외곽선 `#1A1030`, 빛은 왼쪽 위. 기본 팔레트는 `run/RELICS2-ART.md` 3번을 따릅니다.

반영 규칙 (모든 작업 공통)
- 원정 그림(`assets/run/…`)을 넣거나 바꾸면 `run/art.js` 의 **`RUN_ART_VER` 를 올립니다** (예: `'r1'` → `'r2'`). 게임 버전으로 바꾸지 않습니다.
- 주사위 · 트레이 그림(`assets/dice/` · `assets/trays/`)은 `skins.js` 와 `sw.js` 의 **`ART_VER` 를 함께** 올립니다.
- 그림은 **webp**, 투명 배경, 도트는 정수배 확대(nearest). 한 장 30KB 안쪽을 목표로 합니다 (데이터를 크게 쓰지 않게).
- 새 그림은 그 화면 버튼이 보이기 전에 미리 받습니다 (`CLAUDE.md` 「미리 받기 규칙」). 원정 그림은 `run/art.js` 의 `runAssetURLs()` 에 들어가면 자동입니다.
- 확인: `cd dice-heroes && npm test` 통과, 테스트판에서 해당 화면.

## A. 원정 징조 13종 — 「창문 너머 오늘의 날씨」 타로 카드풍 그림

지금 화면: 징조를 고를 때 카드가 **아치형 나무 창문**입니다. 가운데 세로 창살로 반반 나뉘고, 가로 창살이 위에서 44% 높이에 하나 있습니다. 창 안은 그 징조의 하늘색(임시)과 작은 아이콘뿐입니다.
요청: 창 안을 채울 **타로 카드처럼 상징적인 장면** 13장. 창밖을 내다보며 「오늘의 날씨」를 보는 느낌으로 그립니다.

- 파일: `assets/run/omen/<id>.webp`, **96 × 128 px** (3:4). 도트는 2배 확대해서 그려도 됩니다 (192 × 256).
- 위쪽은 아치로 잘립니다 (윗변 양 끝 약 30%가 둥글게 사라짐). 중요한 것은 가운데 · 아래쪽에 둡니다.
- **세로 창살이 가운데를 지나갑니다** → 왼쪽 창 / 오른쪽 창이 한 장면의 두 쪽이 되게 하거나, 대비되는 두 장면을 놓습니다 (예: 왼쪽 해 · 오른쪽 비).
- 넣고 나서: `run/art.js` 의 `OMEN_WIN = []` 에 id 를 적고 `RUN_ART_VER` 를 올립니다.

## B. 덱 아이콘 · 카드 뒷면 — 바이시클 카드풍 (GPT 코딩용)

지금 덱 표시가 공용 카드 아이콘(12×12)이라 어색합니다. **바이시클(Bicycle) 트럼프 뒷면**을 떠올리게 하되, 이 게임에 맞게 바꿉니다.
(상표 그대로는 쓰지 않습니다: 자전거 탄 천사 대신 **주사위 문장 · 날개 달린 주사위**처럼 게임 고유 모티프)

### B-1. 덱 아이콘 (원정 윗바 「덱 보기」 버튼 · 원정 준비 화면)
- 결과물: `dice-heroes/run/relic-art.js` 에 `export const DECK_ART = { deck: { pal: {…}, rows: [16줄 × 16글자] } }` (형식은 `RELIC_ART` 와 같음).
- 모양: 살짝 어긋나게 쌓인 카드 3장, 맨 위 카드에 뒷면 무늬 (테두리 + 가운데 원형 문장).
- 색: 클래식 바이시클처럼 **빨강(#C8102E 계열) + 크림 테두리**, 외곽선 `k`.
- 코드 연결 (같이 고쳐 주세요): `run/ui.js` 의 `hud()` 안 `.pile` 버튼에서 `ico('card', 'xs')` 를 `dotIco('deck', …)` 처럼 `DECK_ART` 를 그리는 함수로 바꿉니다. `relic-art.js` 의 `dotIco` 를 `kind === 'deck'` 도 받게 늘리면 됩니다.

### B-2. 카드 뒷면 (원정 준비 화면 덱 더미 `.rs-back` · 덱 섞기 연출 · 뽑을 더미)
- 결과물 둘 중 하나:
  1. 그림 파일 `assets/run/ui/card_back.webp` (**80 × 112 px**, 2배로 160 × 224 도 가능) + `run/art.js` `UI.ui` 목록에 `'card_back'` 추가 + `run/run.css` `.rs-back` 의 background 를 이 그림으로.
  2. 또는 CSS/SVG 만으로 (`.rs-back` 의 background 에 `data:image/svg+xml`) — 파일 없이.
- 디자인: 대칭(위아래 · 좌우) **선 세공 테두리** + 가운데 **원형 메달리온**(주사위 · 왕관 · 날개). 테두리 안쪽은 촘촘한 마름모 격자. 바이시클처럼 **흰 여백 테두리** 3px.
- 색 2벌: 기본 **빨강**, (선택) 보스 · 하드모드용 **파랑**.

## C. 트레이 바깥 배경 + 트레이별 날아다니는 이펙트

지금: 3D 트레이 상자 바깥(캔버스 남는 칸)이 **단색 짙은 초록 `#0A2A22`** 이라 밋밋합니다 (`style.css` `.tray`).
원정은 막마다 화면 위에 옅은 입자(1막 반딧불 · 2막 눈송이 · 3막 보라 불꽃)를 이미 넣었습니다 (`ambient.js`).

### C-1. 트레이 스킨별 바깥 배경 (그림)
- 파일: `assets/trays/<스킨>/backdrop.webp`, **384 × 288 px** (트레이 칸이 커져도 가운데 기준으로 덮음). 트레이 상자는 그 위에 3D 로 그려지므로 **가운데 60%는 비교적 단순하게**, 테두리 쪽에 분위기를 둡니다.
- 연결: `skins.js` 의 트레이 스킨에 `backdrop: true` 를 두고, 트레이 칸의 CSS background 를 그 그림으로 (`ART_VER` 같이 올림). 코드 쪽은 이 세션에서 연결하겠습니다 — 그림만 오면 됩니다.

| 트레이 | 바깥 배경 제안 | 날아다니는 이펙트 제안 (코드로 입자) |
|---|---|---|
| 기본 (초록 펠트) | 어두운 선술집 나무 바닥 · 촛불 빛 번짐 | 먼지 티끌이 촛불 빛에 떠다님 |
| 클래식 (대리석) | 궁전 회랑 기둥 · 금빛 커튼 | 금가루 반짝임 |
| 왕실 (벨벳) | 왕좌의 방 붉은 카펫 · 샹들리에 | 붉은 꽃잎 · 금빛 반짝임 |
| 심해 | 물속 산호초 · 빛줄기 | 작은 물방울 거품이 위로 |
| 마왕성 | 검은 성벽 · 보라 횃불 | **보라색 작은 불꽃**이 위로 |
| 벚꽃 | 밤 벚꽃길 · 등불 | 벚꽃잎이 흩날림 |
| 용암 | 화산 동굴 · 흐르는 용암 | 불씨 · 재가 위로 |
| 은하 | 별이 쏟아지는 밤하늘 · 초승달 | 별빛 반짝임 · 가끔 별똥별 |

### C-2. 원정 막별 (그림)
- 원정 전투에서는 트레이 스킨 대신 **막 배경**을 깔 수 있습니다: `assets/run/bg/tray_act<1|2|3>.webp` (384 × 288) — 1막 어둠의 숲 · 2막 얼어붙은 폐허 · 3막 마왕성. 넣으면 이 세션에서 연결합니다.

## D. 게임 모드별 배경 · 버튼 · 메뉴 개편

지금: 거의 모든 화면이 **각진 네모 버튼 · 각진 메뉴 판** + 보라 밤하늘 배경입니다. 모드마다 분위기를 나눕니다.
(이 세션에서 이미 넣은 것: 대전 = 별빛 반짝임, 협동 보스전 = 불씨 + 보스 스킬 때 밝게, 원정 = 막별 입자 — 모두 코드 입자, 그림 없음)

### D-1. 모드별 배경 그림 (선택 — 데이터를 크게 안 쓰게 모드당 1장, 60KB 안쪽)
| 모드 | 배경 콘셉트 |
|---|---|
| 대전 (봇 · 온라인) | 별이 보이는 밤의 원형 투기장 · 관중석 실루엣 |
| 협동 보스전 | 보스마다 그 보스의 무대 (화산 · 오크 진영 · 무덤 · 폐허 · 마왕성) — 이미 있는 보스 그림 색과 맞춤 |
| 원정 | 지금 막 배경(`assets/run/bg/`)을 그대로 |
- 파일: `assets/bg/<mode>.webp` (예: `versus.webp`, `boss_dragon.webp`), 360 × 640 세로.

### D-2. 버튼 · 메뉴 판 디자인 가이드 (도트 9-slice)
- 각진 네모 대신 **모서리를 2단 계단으로 깎은 도트 버튼**(픽셀 라운드) + 아래 3px 그림자.
- 9-slice 그림: `assets/ui/btn_<gold|purple|wood>.webp` (각 24 × 24, 가장자리 8px 고정) · 메뉴 판 `assets/ui/panel_<dark|wood|parchment>.webp` (32 × 32, 가장자리 10px).
- 원정 화면은 이미 카드 틀 · 상점 등에서 9-slice(`border-image`)를 씁니다 (`run/run.css` `.rc-in`). 같은 방식으로 전체 버튼(`.pbtn`) · 대화창(`.modal`)에 입힙니다.
- 모드별 색: 대전 = 남색 + 금, 협동 = 짙은 빨강 + 주황, 원정 = 나무 + 양피지.
